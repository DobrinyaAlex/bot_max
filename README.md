# MAX Bot v2 — сеть каналов «Деловая Витрина»

Бот для сбора объявлений, пре-модерации и публикации в каналы мессенджера MAX.
Устойчивые сессии (SQLite), канал модерации, поддержка нескольких админов, детальная статистика.

## Переменные окружения (BotHost → Environment)

Обязательные:
- `MAX_BOT_TOKEN` — токен бота из MAX.
- `CHANNELS_JSON` — список каналов для публикации.
- `ADMIN_CHAT_ID` — ID канала/группы «Модерация» (отрицательное число). Сюда падают заявки и фото на проверку.

Опциональные:
- `ADMIN_USER_ID` — ID админов через запятую (без пробелов). Например: `5518721,987654321`. Дает доступ к командам `/admin` в личке бота.
- `DATA_DIR` — папка данных (по умолчанию `/app/data`).
- `DAILY_AD_LIMIT` — дневной лимит на пользователя (по умолчанию `6`).

## Основные команды

Пользователь:
- `/start` — оформление объявления.
- `/my` — список своих объявлений (удалить / повторить).
- `/cancel` — отменить текущее действие.
- `/help` — справка.

Админ (в личке бота, только для ID из `ADMIN_USER_ID`):
- `/admin stats` — общая статистика.
- `/admin stats channels` — статистика по каждому каналу.
- `/admin pending` — заявки в работе.
- `/admin ban <ID> [минут]` — забанить.
- `/admin unban <ID>` — разбанить.
- `/admin channels` — список каналов с ID.
